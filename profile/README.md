# go-symbolic

🌐 **[Website](https://go-symbolic.github.io)** · 📚 **[Documentation](https://go-symbolic.github.io/docs/)**

**Computer algebra in pure Go. Planned, wave 4 of the go-scikit roadmap.**

**go-symbolic is the planned home of computer algebra for go-scikit**: expressions, polynomials, differentiation, integration, series, limits and solving, as Mathematica's core offers them, and what Maple adds on top (code generation, algebraic numbers, ODE and PDE solving, triangular decomposition, differential algebra, symbolic random variables, groups and tensors). It is in **wave 4**, the last of the roadmap, because nearly everything in it waits for the core: the expression DAG, polynomials, GCD and factorisation.

The organization has no library yet and no release tag: this page, the
[website](https://go-symbolic.github.io) and the
[documentation](https://go-symbolic.github.io/docs/) describe what is planned. The
plan is [PLAN.md](https://github.com/go-scikit/roadmap/blob/main/PLAN.md) and the state of each item is in
[STATUS.md](https://github.com/go-scikit/roadmap/blob/main/STATUS.md) of [go-scikit/roadmap](https://github.com/go-scikit/roadmap).
